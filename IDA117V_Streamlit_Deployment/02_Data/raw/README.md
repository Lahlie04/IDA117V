# Raw data placement - not included in public package

The public repository package intentionally excludes the raw dataset because the exact item-level Custom License terms, source-to-file chain of custody and written redistribution approval have not been evidenced. Approval is not claimed.

To rerun training, an authorised user must place a lawful local copy here using the exact filename:

`Service_Requests_01_April_2026_until_30_May_2026.xlsx`

The analysis code reads that path by default. `.gitignore` excludes raw XLSX/CSV files.

Before publishing any raw data, obtain and archive:

1. the exact source-item URL and dated metadata evidence;
2. the complete item-level Custom License wording;
3. written confirmation that the supplied file is an authorised unchanged export of that item;
4. explicit redistribution permission from the data owner or verified licence terms; and
5. lecturer acceptance of the evidence if required by the assessment.

Until those items exist, publish only the code, documentation, aggregate figures, saved model artifacts and derived evidence contained in this package.
